# homebrew-tap

Personal Homebrew tap for [MouseZoomOnMac](https://github.com/mfeng9/MouseZoomOnMac).

## Install

```sh
brew tap mfeng9/homebrew-tap
brew install --cask mousezoomonmac
```

Homebrew strips the quarantine flag automatically, so no Gatekeeper dance is
needed (the app is adhoc-signed).

First launch: enable **MouseZoomOnMac** in System Settings → Privacy & Security
→ **Accessibility** and **Input Monitoring** (the app shows a prompt).
